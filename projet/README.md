# Pilotage du projet (privé : agence et Claude)

- **Ouvrir** : double-cliquer sur `index.html` (marche en `file://`, sans serveur ni réseau).
- **Modifier** : éditer `donnees.js` (un seul objet `window.PROJET`, champs décrits en tête du fichier), puis recharger la page.
- **Depuis l'interface** : un statut changé reste dans le navigateur. « Exporter donnees.js » télécharge le fichier à jour : remplacez `projet/donnees.js` par lui.
- **Statuts** : tâches `a-faire`, `en-cours`, `attente-client`, `fait` · questions `a-envoyer`, `envoye`, `repondu` · infos `verifie`, `a-confirmer`, `manquant` · assets `a-demander`, `demande`, `recu`.
- **Questionnaire** : « Copier le questionnaire » produit l'e-mail. `questionnaire-client.md` et `infos-a-completer.md` sont les versions texte.
- Aucun chiffre inventé : chaque montant cite son document. Couleurs des statuts validées (daltonisme) avec le validateur du skill dataviz.
